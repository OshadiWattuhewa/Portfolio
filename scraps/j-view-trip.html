How it works
  • Shows the list of trips the user added.
  • Users can delete their trips.
  • Users can share trips with others.
  • The app suggests a rough itinerary from saved items.
  • Users can change it
    • Add new items
    • Change the order
    • Delete items
  • Highlight the number of nights and days.
  • Suggest a route for the itinerary
    • Fastest route by default, with a budget friendly option
    • Open the route directly in Google Maps
  • Based on picked items, the app suggests a rough budget. Users can edit it and add new expenses.
  • Users see all posts they saved from the explore feed.
  • Transport and telecommunication services for the trip country.
  • Upload travel documents: air tickets, visa, accommodation bookings, park tickets.
  • Keeps every trip document in one place.
  • Captures things to do while getting ready for the trip.
  • The system prompts these reminders on or before the trip date.
  • System generated, and users can add or edit items.
Technical delights
  • Saving trips needs sign up or sign in.
  • On first use, prompt for the number of days and nights and rough dates.
  • If skipped, the system decides the duration from saved items, and users can change it.
  • Map suggestions
    • Fastest route by default
    • Users can switch to a budget friendly route
  • Trip dates are needed so push notifications can fire for reminders.
Goal
  • Keep every inspiring post in one place, alongside the rest of the travel info.
  • Most of this info usually comes from people who have been there, so it helps to have it all in one place.
  • Keep all trip documents in one place, ready for airport and accommodation checks.
  • Maintain a reminder list of important things while getting ready for the trip.
